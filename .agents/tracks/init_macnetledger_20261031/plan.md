# Implementation Plan: MacNetLedger Initialization

**Track ID**: `init_macnetledger_20261031`

## Tasks & Milestones

### Phase 1: Core Telemetry Daemon (`macnetledgerd`)
- [ ] **Task 1.1: Database Schema & Migration**
  - Implement SQLite initialization script with WAL mode, synchronous=NORMAL.
  - Tables: `live_state`, `live_summary`, `rollup_5min`, `rollup_1hour`, `hotspot_budget`.
- [ ] **Task 1.2: Darwin Process Lineage Resolver**
  - Bind Darwin `proc_pidpath` via Python `ctypes`.
  - Implement `.app` bundle parser and system daemon mapper (`daemons.json` or inline dictionary).
  - Add LRU cache with TTL to eliminate redundant path lookups.
- [ ] **Task 1.3: Network State & Hotspot Detector**
  - Implement active network probe (`networksetup`, `airport`, or CoreWLAN).
  - Extract SSID and determine `is_hotspot` status.
- [ ] **Task 1.4: NetTop Stream Collector Engine**
  - Wrap `/usr/bin/nettop -P -d -s 2 -L 0 -J bytes_in,bytes_out,interface` with unbuffered pipe reader.
  - Parse CSV deltas, compute rates, and buffer time-series entries.
- [ ] **Task 1.5: Rollup Aggregation & Maintenance Worker**
  - Implement 5-minute bucket flusher.
  - Implement 1-hour rollup worker for older buckets.
  - Implement retention pruning (14-day 5min, 400-day 1hour).

### Phase 2: System Integration & Launchd
- [ ] **Task 2.1: LaunchDaemon Plist Creation**
  - Create `dev.zenmi.macnetledgerd.plist` targeting `/Library/LaunchDaemons/`.

- [ ] **Task 2.2: Automated Install & Permission Scripts**
  - Create `scripts/install.sh` for daemon deployment and database directory provisioning (`0755` dir, `0644` db).

### Phase 3: Menu Bar User Interface
- [ ] **Task 3.1: Menu Bar Pill Component**

### Phase 4: Testing & Verification

## Verification Criteria
1. `macnetledgerd` stays under 1.0% CPU and < 35 MB RSS during continuous 2-second sampling.
2. Closing the MacBook Air lid and reopening it after 10 minutes retains all previous telemetry in SQLite without resetting totals.
3. Network traffic generated by `curl` or `nsurlsessiond` while connected to a mobile hotspot is accurately tagged with `is_hotspot = 1`.
4. Read queries against `ledger.db` from the UI complete in < 5ms without database locking errors (`SQLITE_BUSY`).
